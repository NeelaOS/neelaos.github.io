## 3. Why NeelaOS exists (the motive)

Every Computer Science student hits the same wall in their first semester.

The course says "install gcc", "set up Python", "use Git", "run this in a terminal". On Windows,
that means a long evening of installers, PATH variables, MinGW, WSL, broken compilers and
tutorials written for a different version of everything. Many students lose days before writing
their first real program, and some decide programming "isn't for them" when the real problem was
the setup.

Linux solves most of this. It's what servers, cloud machines, coding contests and most of the
software industry run on, and developer tools install with one command. But for someone who has
only ever used Windows, Linux can feel unfamiliar, technical and a little intimidating. Many
students are told to "just use Linux" and are left to work out the rest themselves.

**NeelaOS closes that gap.** It takes the power of Linux and wraps it in a desktop that already
feels familiar: a taskbar, a Start button, the shortcuts you know, double-click to open. On top of
that, it comes ready for coding, with compilers, languages, VS Code, Git and a friendly Welcome
app that sets up the rest.

The goal is simple: **a student should be able to install NeelaOS and start learning to code the
same day, without fighting their computer first.**

## 4. Feature sections (one block each)

### Familiar from the first click

A taskbar at the bottom, a Start button with the NeelaOS logo, desktop icons, double-click to open,
and the shortcuts you already know: `Win` for Start, `Win + E` for Files, `Win + L` to lock,
`Win + V` for clipboard history, `Win + Shift + S` for screenshots and `Ctrl + Shift + Esc` for
Task Manager. Apps have plain names: Files, Terminal, Settings, Task Manager, Notepad, Photos,
Snipping Tool.

### Ready to code on day one

C and C++ (gcc, g++, clang, gdb, Valgrind, CMake), Python with pip, Java, Node.js with npm, SQLite
and Podman for containers are already installed. VS Code arrives on first boot with a curated set
of extensions for C/C++, Python, Java, Jupyter and web development, plus formatters, themes and
icons.

### Dev packs: one click per course

Open the Welcome app, tick what you need, click Install. Packs include:

- Web Development
- Data Science & AI
- Competitive Programming
- Go & Rust
- Operating Systems & VMs
- Networking & Security
- Android Development
- Graphics & Recording
- Classes & Chat
- Gaming
- Run Windows Programs

### Speaks Ubuntu

Most Linux tutorials are written for Ubuntu. In NeelaOS, `sudo apt install`, `apt update`,
`apt upgrade`, `apt remove` and `apt search` just work. NeelaOS translates them to its own package
manager and shows you the real command, so you learn as you go.

### Git without the headache

NeelaOS ships with **rgit**, a friendly Git companion: `rgit push "message"` saves and uploads your
work in one step, and `rgit undo` takes back your last save. The file manager shows which files
changed, and right-click → _Open in VS Code_ or _Open Terminal Here_ works in any folder.

### Undo anything

Restore points are taken automatically before every update and once a day. If an update or an
experiment breaks something, open **Restore Points**, pick a moment from before the problem, and
go back. Your personal files stay untouched.

### Your everyday PC, too

The **Brave** browser with a NeelaOS start page, Thunderbird for mail, LibreOffice with a familiar
ribbon layout, music, videos, photos, a phone link (NeelaConnect), printing and more. Microsoft
Office documents keep their layout thanks to metric-compatible fonts.

### Beautiful by default

A navy, teal and gold design system across the boot screen, login, desktop, apps and terminal.
Neela Dark and Neela Light themes, six original wallpapers, a white cursor and custom icons.
VS Code follows your theme.

### Safe, stable, up to date

NeelaOS is built on **Fedora**, one of the most respected Linux distributions, and receives its
security updates. Secure Boot works out of the box, and graphics drivers, including NVIDIA, are set
up for you.

## 6. How to get it (install page)

**Headline:** Your new PC, ready in 3 steps.

1. **Download** the NeelaOS ISO (and check it with the included `.sha256` file).
2. **Write it to a USB stick** (8 GB+) with Rufus, Fedora Media Writer or balenaEtcher.
3. **Boot and install.** Try NeelaOS live first, then click _Install NeelaOS_. Neela Setup guides
   you through language, disk and account. You can keep Windows alongside it.

After the first login, stay online for a few minutes while the Welcome app finishes setting up
VS Code, Brave, codecs and drivers.

**What you need:** a 64-bit PC, 4 GB RAM (8 GB recommended), 40 GB free disk space, a USB stick.

**Button:** Download NeelaOS · _View install guide_

## 7. FAQ

**Is NeelaOS free?**
Yes, completely: no licence, no subscription, no ads.

**Is it Windows?**
No. NeelaOS is Linux (based on Fedora) designed to feel familiar to Windows users. Windows programs
don't run natively.

**Can I still use Microsoft Office?**
Office in the browser works, and LibreOffice opens and saves Word, Excel and PowerPoint files with
their layout intact. The desktop version of Microsoft Office doesn't run.

**Can I play games?**
Many Windows games run through Steam's Proton (available as a Dev pack). Games with anti-cheat
systems usually don't.

**Can I keep Windows?**
Yes. Neela Setup can install NeelaOS alongside Windows, and you choose which one to start each time.

**Will it run on my laptop?**
Most 64-bit laptops and desktops from the last ten years run NeelaOS well. Try it live from the
USB first; nothing changes on your PC until you install.

**What if I break something?**
Open Restore Points and go back to a moment before the problem. Your files are kept.

**Is it safe?**
NeelaOS uses Fedora's packages, security updates and signed boot chain, and only installs software
from official sources.

**Why "Neela"?**
_Neela_ means blue, the colour at the heart of the NeelaOS look, from navy and sea blue to teal.
