Why NeelaOS exists

Every CS student hits the same wall in their first semester.

The course says “install gcc”, “set up Python”, “use Git”, “run this in a terminal”. On Windows, that means a long evening of installers, PATH variables, MinGW, WSL, broken compilers and tutorials written for a different version of everything. Some students decide programming “isn’t for them” when the real problem was the setup.

Linux solves most of this, but for someone who has only ever used Windows it can feel unfamiliar and a little intimidating. NeelaOS closes that gap. It wraps the power of Linux in a desktop that already feels familiar, and it comes ready for coding.

A student should be able to install NeelaOS and start learning to code the same day, without fighting their computer first.

Git without the headache

NeelaOS ships with rgit: rgit push "message" saves and uploads your work in one step, and rgit undo takes back your last save. The file manager shows which files changed, and right-click → Open in VS Code works in any folder.

How to get it

Your new PC, ready in 3 steps.

Free, no account needed. Try NeelaOS live from the USB first; nothing changes on your PC until you install.

  1. Download

    Download NeelaOS-x86_64.iso and its .sha256 file from GitHub Releases, then check the download is intact:

    Get-FileHash NeelaOS-x86_64.iso
    sha256sum -c NeelaOS-x86_64.iso.sha256

    First line: Windows PowerShell. Second line: Linux.

  2. Write it to a USB stick

    Use a USB stick of 8 GB or more (it will be erased) with Rufus (choose DD image mode when asked), Fedora Media Writer or balenaEtcher.

  3. Boot and install

    Restart and open the boot menu (usually F12, F11, F9, Esc or F2), pick the USB stick and choose Start NeelaOS.

    Try it live, then click Install NeelaOS. Neela Setup guides you through language, disk and account. You can keep Windows alongside it.

Neela Setup — After installing

After the first login

Restart, remove the USB stick and log in. Stay online for a few minutes while the Welcome app finishes setting up VS Code, Brave, codecs and drivers.

Keep the default Btrfs layout to get restore points. Want a separate “D: drive” for your files? Choose custom partitioning and make a separate /home partition.

Try it in VirtualBox first
  • New VM → Type Linux, Version Fedora (64-bit). Not “Other”: that makes a 32-bit VM.
  • Enable EFI, 4–6 GB memory and 2–4 CPUs.
  • A 40 GB disk (smaller disks fail the installer’s space check).
  • Display → VMSVGA, 128 MB.
  • Attach the ISO and start. After installing, remove the ISO and restart.

FAQ

Good questions, short answers.

Is NeelaOS free?

Yes, completely: no licence, no subscription, no ads.

Is it Windows?

No. NeelaOS is Linux (based on Fedora) designed to feel familiar to Windows users. Windows programs don't run natively.

Can I still use Microsoft Office?

Office in the browser works, and LibreOffice opens and saves Word, Excel and PowerPoint files with their layout intact. The desktop version of Microsoft Office doesn't run.

Can I play games?

Many Windows games run through Steam's Proton (available as a Dev pack). Games with anti-cheat systems usually don't.

Can I keep Windows?

Yes. Neela Setup can install NeelaOS alongside Windows, and you choose which one to start each time.

Will it run on my laptop?

Most 64-bit laptops and desktops from the last ten years run NeelaOS well. Try it live from the USB first; nothing changes on your PC until you install.

What if I break something?

Open Restore Points and go back to a moment before the problem. Your files are kept.

Is it safe?

NeelaOS uses Fedora's packages, security updates and signed boot chain, and only installs software from official sources.
