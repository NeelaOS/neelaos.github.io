Why NeelaOS?

Most students learn to code on Windows, then spend their first weeks fighting setup.

The course says “install gcc”, “set up Python”, “use Git”. On Windows that means installers, PATH variables, MinGW, WSL and tutorials written for a different version of everything. Linux solves most of this, but it can feel unfamiliar to someone who has only ever used Windows.

NeelaOS closes that gap: a familiar Windows-like desktop paired with every development tool already installed.

Install NeelaOS and start learning to code the same day, without fighting your computer first.

Download & install

Download NeelaOS and install it in 5 steps.

Free, no account needed. Try it live from the USB first; nothing changes on your PC until you install.

{{#unless release.available}}

{{release.comingSoonText}} Watch on GitHub →

{{/unless}}

  1. Download and verify

    Download {{release.isoFile}} ({{release.isoSize}}) and {{release.isoFile}}.sha256, then check the file is intact:

    WindowsGet-FileHash {{release.isoFile}}
    Linuxsha256sum -c {{release.isoFile}}.sha256

  2. Write it to a USB stick

    Use an 8 GB+ stick (it will be erased) with Rufus in DD image mode, Fedora Media Writer or balenaEtcher.

  3. Boot from the USB

    Restart, open the boot menu (usually F12 F11 F9 Esc or F2), pick the USB stick and choose Start NeelaOS.

  4. Try it or install it

    NeelaOS runs live without changing anything. Click Install NeelaOS and Neela Setup asks for language, keyboard, disk and account. Use the whole disk or install alongside Windows, and keep the default Btrfs layout for restore points.

  5. Restart and log in

    Remove the USB stick and log in. Stay online for 10–20 minutes while the Welcome app sets up VS Code, Brave and media codecs.

After you install

Staying up to date, and good to know.

Neela Store — Updates

One place for every update

Fedora updates and NeelaOS improvements arrive together. Install them from Neela Store → Updates, or in the Terminal:

sudo apt update && sudo apt upgrade

A restore point is created automatically before every update, so you can always roll back.

Good to know
  • Windows-only apps (Microsoft Office desktop, Adobe, anti-cheat games) don't run. Use LibreOffice or Office online; many games work through Steam's Proton, and the Run Windows Programs pack handles simple .exe files.
  • Ubuntu .deb files can't be installed. Use Neela Store (Flatpak) or the app's .rpm version.
  • Brave installs on first boot, so the live USB has no visible browser yet.
  • In the Terminal, copy and paste are Ctrl+Shift+C / V. Ctrl+C stops a running program.
